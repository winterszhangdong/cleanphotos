# 产品说明

视觉与动效以 `docs/ui-design.md`（暗房）为准，2026-10-11 用户最终决定见其第 1 节。旧「印样」方案作废。

## 产品定位

这是一个极简相册清理 App。

产品目标是帮助用户快速整理相册，通过沉浸式大图、左右切换和上下处理手势完成照片清理。

核心操作：

- 左右滑动：切换当前查看的照片
- 向上滑动：收藏照片
- 向下滑动：移动到 App 内垃圾桶（仅写 DataStore，不触发系统弹窗）
- 操作后：可以撤回
- 操作前：不需要确认

相册里的视频和照片走同一套列表、清理、收藏、垃圾桶和看过。网格不画播放图标，也不标动态照片。清理页和垃圾桶全屏预览会播放：当前页停稳后静音自动开始，视频和动态照片都只播一次。视频播完回到第 0 帧并暂停，动态照片播完露出静态图。视频按自己的比例居中，不拉变形。上下或左右拖动立刻定格在当前帧，翻页弹簧或飞出结束前定格留在离开的那张上。单击视频切换播放 / 暂停；暂停、未开始、播完时显示玻璃中心播放键。停稳后等待自动播放的那段时间不闪中心键。拖动或点按进度后，从该位置直接开始播放。详情打开时视频有进度行和声音开关。动态照片右上角有「动态」胶囊，点它从头再播一次，始终无声。声音只在这次进入该页时记住，默认静音。系统关闭动画时不自动播放。相似对比页不播放。网格右下角显示时长（`m:ss`，满 1 小时为 `h:mm:ss`）。清理页视频的时长写在进度行两端，文件信息行只留名称 · 大小。

权限：

- Android 13+ 同时请求 `READ_MEDIA_IMAGES` 和 `READ_MEDIA_VIDEO`；Android 14+ 再带 `READ_MEDIA_VISUAL_USER_SELECTED`（只选部分照片）。Android 12 及以下仍是 `READ_EXTERNAL_STORAGE`，图片和视频都覆盖。
- 有图片权限或 Android 14 的部分访问就可以用照片。拒绝视频不影响照片。
- 已有图片权限、缺少视频权限的老用户：每次冷启动进入照片页请求一次视频权限。系统拒绝两次后自己不再弹，不另存标记。
- 只有图片和视频都已完整授权时，才把「查询结果里没有的 id」当成已从系统删除并清理收藏 / 看过 / 垃圾桶记录。缺视频权限时查询不含视频，不能做这次清理，否则会误删视频的记录。

## 核心用户流程

```text
打开 App
  ↓
查看全部照片
  ↓
按日期浏览照片分组
  ↓
点击某张照片
  ↓
进入全屏清理页
  ↓
左右滑动自由切换照片
  ↓
向上滑动收藏，或向下滑动移动到 App 内垃圾桶（仅写 DataStore）
  ↓
自动切换到下一张照片
  ↓
底部显示撤回提示
```

## 全部照片页

全部照片页用于展示用户相册中的所有照片（排除已收藏和已移入垃圾桶的照片）。

页面内容：

*   顶栏没有小标题。大号数字是当前范围叠上「只看没看过」之后的张数，单位英文 photo / photos、中文「张」。副文字：大文件 / 截图 / 聊天为「· 2.1 GB」（这些可见照片的 size 之和，null 记 0）；全部 / 那年今天没有副文字；多选时数字是已选张数，副文字「· 已选择」。加载中保持张数骨架和「正在读取相册…」。右侧只剩 ⋯。
*   顶栏下面一行范围按钮：全部 / 相似 / 大文件 / 截图 / 聊天 / 那年今天。单选，默认全部，不持久化，按钮上不写数量。「那年今天」数量为 0 且当前不是这个范围时不显示，并排在最后。
*   往下翻时顶栏和范围行一起收起，往上拨展开。列表回到顶部、菜单打开、多选、切换范围时强制展开。状态栏下有一条暗室底色，照片不从状态图标下面穿过去。
*   分组看范围。全部、那年今天：年份分隔 + 按天，日期行「日 + 月 · 周几」，每天最多 8 张，那年今天每年正好一组。截图、聊天：年份分隔 + 按月，月份标题中文「10 月」、英文用月份短名，不截断。大文件：不分组，平铺网格，没有年份分隔、没有日期行，格子左下角写文件大小。日期行和月份标题右侧都是「已看 / 总数」（已看数相纸白），整组看完显示「已看完」。没有箭头，右侧文字仍可点，从这一组第一张进入清理页。缩略图没有未看光点。
*   底部玻璃导航胶囊：照片 / 收藏 / 垃圾桶（带中性灰计数）。相似也在这一页里，导航保持显示。

⋯ 菜单分三段，段之间有分隔线。大文件范围隐藏排序这一段，只留后两段：

*   排序：「最新优先」（默认）/「最早优先」。选完关闭菜单，仍出现顺序提示。大文件不显示这一段。
*   「只看没看过」开关。开着时 ⋯ 右上角亮 6dp 相纸白小点。相似范围不吃这个开关。
*   语言，右侧写当前语言。

空状态：

*   全部 + 只看没看过 + 0 张，且相册里还有照片：现有「全部看过了」（收藏 N / 垃圾桶 N 张 / 待释放 X GB）。文字按钮「显示看过的」关掉开关。垃圾桶非空时仍有「看看垃圾桶」。
*   其它范围 + 只看没看过 + 可见 0 张、但该范围本身有照片：「这里都看过了」+「显示看过的」（关掉开关）。
*   范围本身 0 张、且相册里仍有照片：对应标题（「没有截图」/「没有大文件」/「没有聊天软件存图」/「那年今天没有照片」）和「显示全部照片」，点了切回全部。
*   相册本身为空时仍是「相册里还没有照片」。

照片展示规则：

*   全部、截图、聊天、那年今天按菜单里的最新 / 最早排。大文件固定按 size 从大到小（相同再按 dateTaken 新到旧），菜单里的排序留着，切回别的范围照常生效。排序不改变相似分组。
*   全部和那年今天每天最多 8 张；截图、聊天按月不截断；大文件平铺不截断。
*   点击照片进入清理页，传递 photoId + 当前列表用的 sortOrder（大文件是 LargestFirst，其它范围是菜单里的排序）+ 当前范围对应的 filterMode + scope=AllPhotos + unseenOnly，确保清理页翻页顺序与网格一致。
*   相似范围不能多选。点组内缩略图是改保留项，不进清理页。
*   点击底部「收藏」进入收藏页。
*   点击底部「垃圾桶」进入垃圾桶页。
*   已收藏的照片自动从全部照片页隐藏，仅在收藏页可见。
*   照片页不再显示垃圾桶提醒。

过滤说明：

*   先按范围，再叠「只看没看过」。两者都不持久化，重新进入页面后恢复默认（全部、开关关）。
*   「只看没看过」只显示未看过的照片。相似范围忽略它。
*   「截图」：relativePath 或 bucketName 含 screenshot / 截屏 / 截图（不区分大小写）。
*   「大文件」：size ≥ 10 MB（10 × 1024 × 1024 字节），图片和视频同一阈值；size 为 null 不算。
*   「聊天」：relativePath 含 weixin / whatsapp / telegram，或以 Pictures/QQ/ 开头（不区分大小写）。
*   「那年今天」：有效拍摄时间（dateTaken，≤0 视为没有）按系统时区换成本地日期，月、日都等于今天且年份早于今年。2 月 29 日的照片只在 2 月 29 日命中。图片和视频都算。今天只在照片列表或看过状态变化时重算，跨过午夜不会自动刷新。

## 相似照片页

相似合在照片页里。范围按钮选「相似」后，列表换成相似分组卡片，底部导航保持显示。列表没有自己的顶栏。点缩略图进入这一组的对比页，底部导航隐藏。顶栏大号数字是组数，单位「组」（英文 group / groups），副文字「· 可移走 N 张」。N 是当前所有组里标成移走的张数。

只看全部照片里的图片（已经排除收藏和垃圾桶，也不含视频）。按拍摄时间升序，相邻两张间隔不超过 10 秒、而且 64 位 dHash 的汉明距离不超过 10，就连成一组（只和前一张比）。至少两张才成组。没有拍摄时间的不参与。10 秒内没有邻居的照片不算哈希。成组之后，只给组里的照片用约 512px 长边的灰度图算拉普拉斯方差，作为清晰度。取图失败的那张跳过，不参与推荐。

第一次切到「相似」才开始比对。切走再回来不重新计算。比对过程中显示「正在比对 已完成 / 要算的张数」。要算的张数先是哈希候选，清晰度阶段再加上组内张数，所以分母会变大一次。哈希和清晰度都算完才列出分组，不先出列表再改推荐。没有相似组时显示「没有找到相似照片」。

每一组是一张卡片：最早一张的拍摄日期时间，下面一行缩略图。每张可以标成留下或移走。默认把最清晰的一张标成留下，其余标成移走。没有清晰度时，推荐退回像素数最多（相同则文件更大，再相同则拍摄更早，仍相同则 id 更小）。留下是原色，不打勾。移走是原色，右上角一枚相纸白圆，没有黑边，图标是垃圾桶。可以留下多张，也可以全部移走。点缩略图打开对比页并停在那一张，不在列表里改标记。

卡片底部是中性玻璃胶囊。有标成移走的就写「移走 N 张」，一张都没标移走就写「都留下」。不弹确认框。提交时：移走的进垃圾桶，还会留在全部照片里的留下有两张及以上时记一条已处理记录。该组随后从列表消失。撤回胶囊在导航上方，一次撤回这次提交的移走和已处理记录。都留下时胶囊写「已留下」，用来撤回这条记录。相似下不能多选。排序不影响分组。「只看没看过」对相似无效。

对比页全屏。顶部是返回和「2 / 5」。当前这张是推荐、有清晰度、并且仍是留下时，再写「推荐 · 最清晰」；标成移走时改写「移走」。中间大图保持原色。底部是同一组的胶片条，当前一张有相纸白描边。点胶片条直接切到那张，保留当前缩放。上滑标成留下（勾），下滑标成移走。已经是这一侧时标记不变。照片弹回原位，只改标记，不飞走。方向提示在松手后淡出，不跟着回弹换字。返回列表不提交。提交用和列表相同的胶囊，成功后回到列表并出现撤回胶囊。

## 清理页

清理页用于快速处理单张照片。手势语义由入口 scope 决定。

页面内容：

*   全屏照片（支持双指缩放、双击缩放）
*   顶部「当前照片所在那一天」的会话进度条（一格一张，不显示数字；>40 张为连续比例条）
*   进入时只显示顶部进度条。静态图和动态照片点一次才显示左上角返回、日期和星期·拍摄时间、底部文件名 · 文件大小；再点一次收回。视频单击改为切换播放 / 暂停：用户暂停时展开上述详情和进度行（时长在进度行两端，文件信息不再重复），继续播放时收回。左右滑动或上下拖动一开始就收回。静态图和动态照片松手后不自动再出现；视频若仍是用户暂停，回弹后详情回来。动态照片详情打开时右上角有「动态」胶囊。没有「去垃圾桶 / 回到照片」，也不显示「上滑收藏 / 下滑移走」
*   视频和动态照片在当前页停稳后静音自动播放（规则见 interaction.md）。网格和相似对比页不播放
*   上滑：琥珀显影光 + 提示圆，从收藏进入时为「松手取消收藏」（空心琥珀星）
*   下滑：照片随距离压暗去色（中性，无红色）
*   操作后底部撤回胶囊（带照片小样、4 秒倒计时）
*   两天之间满足条件时出现「这一天整理完了」小结插页（见 interaction.md）

不显示的内容：

*   清理进度数字 `XX / 总数`

用户操作（AllPhotos scope，从全部照片页进入）：

```text
左滑：切换到下一张照片
右滑：切换到上一张照片
向上滑动：收藏照片（写入 App DataStore，不触发系统授权）
向下滑动：移动到 App 内垃圾桶（仅写 DataStore，不触发系统授权）
点击撤回：恢复上一次操作
点击照片：显示或收回返回、日期和文件信息
```

用户操作（Favorites scope，从收藏页进入）：

```text
左滑：切换到下一张照片
右滑：切换到上一张照片
向上滑动：取消收藏（移除 App DataStore 收藏条目，不触发系统授权）
向下滑动：移动到 App 内垃圾桶（仅写 DataStore，不触发系统授权）
点击撤回：恢复上一次操作
点击照片：显示或收回返回、日期和文件信息
```

左右滑动只改变当前查看照片，不执行收藏、移动到垃圾桶或撤回相关操作。进入清理页时当前照片立即标记为已看过，水平滑动时离开的照片也标记为已看过。整个会话可连续左右翻页并跨天；跨天时日期里程表滚动、进度条切换、轻触感一次，不阻塞。滑动手感硬性要求见 interaction.md。

向上或向下操作成功后，当前照片从清理队列移除，并自动进入下一张可清理照片。

收藏和取消收藏都操作 App 内 DataStore，不触发系统授权。

## 收藏页

收藏页用于展示用户在 App 内收藏的所有照片。

### 收藏语义

*   "收藏" = 写入 App 内 DataStore（AppFavoriteStore），不触发系统授权。
*   "取消收藏" = 从 App 内 DataStore 移除收藏条目，不触发系统授权。
*   首次启动时将系统 IS_FAVORITE 一次性迁移到 App DataStore。
*   照片页自动隐藏已收藏照片。

### 用户可见规则

*   照片页不显示已收藏的照片。
*   收藏页显示已收藏的照片。
*   点击照片进入清理页（scope = Favorites，上滑 = 取消收藏，下滑 = 移入垃圾桶）。
*   与照片页同构：年份分隔、日期分组、每天前 8 张；日期行右侧只写这一天收藏张数。顶栏没有小标题，右侧留空：大号张数 + 单位（中文「张」，英文 favorite / favorites）。琥珀只出现在单位后面的 5dp 小点（左距 6dp）；照片不加描边、不显示未看标记。

## 垃圾桶页

垃圾桶页用于展示已经移动到 App 内垃圾桶的照片。App 内垃圾桶是 DataStore 管理的软删除状态，不直接操作系统的 MediaStore IS_TRASHED 字段。

### 垃圾桶语义

*   "移入垃圾桶" = 写入 App 内垃圾桶（DataStore），不删除系统媒体文件，不触发系统授权弹窗。
*   "移出垃圾桶" = 从 App 内垃圾桶移除（删除 DataStore 记录），照片重新显示在 App 首页，不触发系统授权弹窗。
*   "清空垃圾桶" = 对 App 内垃圾桶中的全部照片发起系统永久删除，这是**唯一**允许删除系统媒体文件的入口，需要 App 确认框 + 系统删除授权。

### 用户可见规则

*   照片页不显示 App 内垃圾桶中的照片。
*   清理页会话列表不包含 App 内垃圾桶中的照片。
*   垃圾桶页显示 App 内垃圾桶中的照片。
*   外部相册、文件管理器、电脑在清空前仍可能看到这些文件。

### 默认网格模式

*   查看 App 内垃圾桶中的照片，以缩略图网格展示。
*   作为 tab，不显示返回箭头。顶栏没有小标题：大号张数 + 单位（中文「张」，英文 item / items），右侧 `选择`。
*   托盘色「清空后可释放 X GB」卡片（读 MediaStore SIZE）+ 删除红描边 `清空` 胶囊。最早一张移入已满 30 天时，副文字改为「最早一张已放 N 天」（英文 Oldest item: N day(s) in trash）；否则仍是「只在 App 内标记，清空时才真正删除」。没有间隔、没有关闭按钮，清空后卡片消失。
*   缩略图降饱和，右下角显示文件大小。
*   底部玻璃导航胶囊，选中「垃圾桶」。全屏预览不展示底栏。
*   点击缩略图：进入全屏预览模式。
*   点击 `选择`：进入多选模式。
*   点击 `清空`：弹出确认框后永久删除全部垃圾桶照片。

### 多选模式

*   通过默认网格模式顶部 `选择` 按钮进入。
*   顶部栏与默认顶栏同高：左侧 `取消`，中间 `已选择 {count} 项`，右侧 `移出垃圾桶`。
*   点击缩略图只切换选中状态，不进入预览。
*   已选照片缩到 0.86、恢复原色、右上角相纸白圆勾；顶栏下显示选中总大小；多选时隐藏「可释放」卡片和「清空」。
*   `移出垃圾桶` 在未选中任何照片时禁用。
*   批量移出成功后：清空选中集合，退出多选模式，返回默认网格模式，显示成功提示。

### 全屏预览模式

*   通过默认网格模式点击缩略图进入。
*   全屏黑底沉浸式展示照片，保持原始宽高比。
*   左右滑动切换垃圾桶中的上一张 / 下一张照片。
*   顶栏显示 `垃圾桶 i / N`，动态照片在顶栏右侧放「动态」胶囊。信息行显示文件名 · 大小、拍摄日期 · N天前移入。视频在信息行上方放进度行（两端时间、轨道、声音钮）；单击照片切换播放 / 暂停，暂停、未开始、播完时照片中央有中心播放键。开播前的等待不闪中心键。拖动或点按进度后，从该位置直接开始播放。动态照片单击不做任何事。不提供单张永久删除。
*   底部固定按钮：`移出垃圾桶`。
*   移出成功后：从预览队列移除当前照片；若队列后续还有照片则显示下一张，若变为空则关闭预览返回默认网格模式。

### 清空垃圾桶

*   仅在默认网格模式顶部 `清空` 按钮触发。
*   点击后弹出 App 内确认框：
    *   标题：`永久删除 N 张照片？`
    *   内容：`会释放 X GB。删除后无法撤回，系统还会再请求一次授权。`
    *   次操作：`取消`
    *   主操作：`删除`
*   这是**唯一**允许永久删除的入口。
*   确认后发起系统永久删除授权；用户取消系统授权时静默处理，不显示额外错误提示。
*   刷新后确认已从图库消失的照片，按文件大小累加进「累计已释放」（DataStore `total_freed_bytes`，只增不减；大小未知按 0，合计为 0 不写）。全部成功、部分残留、Android 8–10 部分删除都只计真正删掉的。进程重建后没有删除前快照的那一次不计入。
*   垃圾桶为空时，正文下方显示「累计已释放 X」（英文 Freed X in total）。累计为 0 不显示。其它页面不显示。刚清空的这一次包含在累计里。

## 产品规则

必须遵守：

*   不在操作前弹确认框。
*   日常操作（收藏、取消收藏、移入垃圾桶、移出垃圾桶、撤回）均为 App 内 DataStore 操作，不触发系统授权弹窗，不弹 App 自定义确认框。
*   "清空垃圾桶"是唯一触发系统永久删除的入口，需要 App 内确认框 + 系统删除授权。
*   每次有效操作后都显示撤回提示。
*   第一次进入清理页显示滑动教学。
*   教学完成后不再显示。
*   首页按范围分组：全部和那年今天按天，截图和聊天按月，大文件平铺。相似换成相似卡片。
*   首页支持排序（最新优先 / 最早优先）、范围（全部 / 相似 / 大文件 / 截图 / 聊天 / 那年今天）和「只看没看过」开关。大文件固定按大小排，菜单不显示排序。选择不持久化。相似合在照片页里。照片页不显示垃圾桶提醒。
*   清理页必须保持沉浸式全屏体验。
*   清理页照片保持原始比例居中显示（Fit），不裁切、不拉伸；没铺满的地方用同一张照片放大 1.2 倍、模糊 36dp、亮度压到 40% 做环境光（API 31 以下不画，露出暗房底色）。环境光预先做好，左右滑入时和照片一起出现。
*   清理页支持双指缩放和双击缩放，缩放中禁用滑动手势。
*   清理页不再显示底部进度数字。
*   清理页撤回是底部雾色胶囊。没有 Favorite / Trash 指示器。上滑色带写「收藏」，下滑色带写「移到垃圾桶」。
*   水平滑动只用于切换照片，垂直滑动只用于执行清理动作。
*   清理页手势语义由 scope 决定（AllPhotos 上滑收藏，Favorites 上滑取消收藏）。
*   用户取消系统授权时（清空垃圾桶永久删除），静默处理，不显示额外错误提示。
