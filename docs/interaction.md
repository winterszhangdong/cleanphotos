# 交互设计

视觉与动效规格见 `docs/ui-design.md`（第 1 节为 2026-10-11 用户确认的最终决定，第 2–4 节为设计系统、动效与逐屏规格）。旧「印样」描述已全部作废。

## 交互总览

App 的核心交互是：

```text
浏览照片
选择照片
进入清理页
左右滑动切换照片
上下滑动处理照片
操作后撤回
```

## 首页交互

### 页面标题区

照片页顶栏没有小标题。大号数字是当前范围叠上「只看没看过」之后的张数，单位英文 photo / photos、中文「张」。副文字：大文件 / 截图 / 聊天为「· 大小合计」（可见照片 size 之和，null 记 0）；全部 / 那年今天没有副文字；相似时数字是组数、单位 group / groups 或「组」，副文字「· 可移走 N 张」；多选时数字是已选张数，副文字「· 已选择」。标题区占满按钮左侧剩余宽度，右侧只剩一颗 ⋯。宽度不够时副文字换到大数字下方单独一行，仍放不下才省略号截断。收藏页、垃圾桶页顶栏见各自章节。

「只看没看过」开着时，⋯ 右上角亮 6dp 相纸白小点。张数变化用里程表逐位滚动（增加向上、减少向下）。

顶栏下面一行范围按钮，单选，默认「全部」，不持久化，按钮上不写数量：全部 / 相似 / 大文件 / 截图 / 聊天 / 那年今天。「那年今天」数量为 0 且当前不是这个范围时不显示，并排在最后。切换范围时列表回到顶部，顶栏和范围行展开。不播放网格重排：照片和日期直接出现在新位置，不从旧位置飞入。

往下翻时顶栏和范围行作为一个整体跟手收起（quick return），往上拨展开。松手停在半途时，收起超过一半就吸到完全收起，否则吸到完全展开（弹簧 `MotionSprings.Settle`）。列表已经在顶部、⋯ 菜单打开、语言弹层打开、多选中、或刚切换范围时，强制完全展开。偏移只在 `graphicsLayer` 里读。系统「移除动画」打开时直接跳到终点，不走弹簧。状态栏下有一条暗室底色，照片不从状态图标下面穿过去。网格和相似列表都收起。收藏页和垃圾桶页这一轮不收起。

列表：年份分隔行（带细线，跨年时出现）；日期行「日 + 月 · 周几」，右侧 mono「已看 / 总数」（已看数相纸白 500），整天看完显示「已看完」；没有箭头，右侧文字仍可点。每天最多显示前 8 张。缩略图不画未看光点。已看 / 总数按当前范围里这一天的张数算（例如「大文件」下只数这一天的大文件）；「只看没看过」开着时仍按范围内整天算，不随开关缩小。

显示：启动时向系统申请当前屏幕支持的最高刷新率（`preferredDisplayModeId` / `preferredRefreshRate`）；高刷真机可到 90/120，模拟器通常仍 60。

加载中：骨架呼吸（#171513 ↔ #211E1B，2.4s，相邻错开 200ms），张数骨架占位，旁边「正在读取相册…」，读完后从 0 滚到实际值。缩略图取系统缩略图（Android 10+ `loadThumbnail`，图片和视频都可用；8–9 退回按格子大小解码原图，视频按 mimeType `video/*` 取首帧）。视频格子右下角显示时长（`m:ss`，满 1 小时 `h:mm:ss`），不画播放图标。显影范围：首屏错开显影每个进程只播一次（照片、收藏各一次）——冷启动后网格首次出现时首屏那几格沿对角线错开显影，之后切 Tab、进清理页再返回都直接显示；开始滚动后新进入的格子不显影，解码后直接显示；命中内存缓存一律直接显示。网格格子不叠 Crossfade；非多选时不挂选中动画层。

空状态按这个顺序：

```text
相册里一张都没有：仍是「相册里还没有照片」
范围本身 0 张（大文件 / 截图 / 聊天 / 那年今天），相册里还有别的照片：「没有截图」等 + 「显示全部照片」，切回全部
全部 + 只看没看过 + 可见 0 张：「全部看过了」（决定 11）。三个数字为 收藏 N / 垃圾桶 N 张 / 待释放 X GB；垃圾桶非空时给「看看垃圾桶」；文字按钮「显示看过的」关掉开关
其它范围 + 只看没看过 + 可见 0 张、但该范围本身有照片：「这里都看过了」+「显示看过的」，关掉开关。不用晾绳，不用三个数字
```

不用琥珀、不用删除红。

回到前台：从后台回到 App 时重新读一次图库（在系统相册或其它 App 里增删照片后不用重开 App）；冷启动那次由各页面自己加载，不重复读；距上次读取不足 2 秒（例如刚从系统删除确认回来）跳过。几处同时触发读取时串行执行，后发起的结果不会被先发起的旧结果覆盖。进程被系统回收后直接回到清理页时，先读图库再建立会话，从回收前正在看的那张照片开始（不是当初进入的那张）；起点照片已不在当前范围加「只看没看过」的结果里（例如开关开着、进入时就被标为看过）时落到排序上它后面最近的一张，后面没有就取前面最近的一张；会话建立不了（读取失败、起点照片已被删除）时提示约 2.5 秒后回到入口页。

读屏（TalkBack，安卓）：清理页的上下滑和左右翻页另以自定义操作提供——「收藏 / 取消收藏」「移入垃圾桶」「下一张」「上一张」，执行的路径、动画和撤回与手势完全相同；照片页缩略图双击打开清理页（多选中为切换选中），双击按住等同长按进入多选。系统删除确认期间进程被回收时，回到垃圾桶后刷新列表，已清空则提示「已清空垃圾桶」（没有溶解动画）。

首次授权：整屏说明 + 「允许访问照片」。Android 13+ 同时请求 `READ_MEDIA_IMAGES` 和 `READ_MEDIA_VIDEO`；Android 14+ 额外提供「只选部分照片」（`READ_MEDIA_VISUAL_USER_SELECTED`）。拒绝且不再询问时主按钮改为「去系统设置开启」。只拒绝视频不影响照片使用。已经授过图片权限、还没有视频权限的老用户，每次冷启动进入照片页再请求一次视频权限（系统拒绝两次后自己不再弹，不另存标记）。

### 范围按钮与 ⋯ 菜单

范围在顶栏下面的按钮行里切换，不在菜单里。按钮不写数量。规则：

```text
默认「全部」
顺序：全部 / 相似 / 大文件 / 截图 / 聊天 / 那年今天
「那年今天」数量为 0 且当前不是这个范围时不显示；当前已经是这个范围时，即使结果变成 0 也仍显示，并留在最后
先按范围筛，再叠「只看没看过」
截图：relativePath 或 bucketName 含 screenshot / 截屏 / 截图（不区分大小写）；字段为 null 不命中
大文件：size ≥ 10 MB（10 × 1024 × 1024 字节），图片和视频同一阈值；size 为 null 不算
聊天：relativePath 含 weixin / whatsapp / telegram，或以 Pictures/QQ/ 开头（不区分大小写）；只看 relativePath
那年今天：dateTaken（毫秒，≤0 或没有视为不命中）按系统时区换成本地日期，月、日等于今天且年份早于今年；2 月 29 日只在 2 月 29 日命中；图片和视频都算。今天只在照片列表或看过状态变化时重算，跨过午夜不会自动刷新
范围和「只看没看过」都不持久化，重新进入页面后恢复默认
从照片页进入清理页时，AllPhotos scope 的会话只在「范围 + 只看没看过」的结果里翻页；Favorites scope 仍跳过过滤，也不吃这个开关
相似不是 PhotoFilterMode：列表换成分组卡片，不吃「只看没看过」，不能多选，排序不影响分组
```

右上角只剩 ⋯。点开玻璃菜单（缩放 0.92→1 + 淡入 180ms；按钮反白；列表压暗 48%）。菜单分三段，段之间一条细线：

```text
排序
  最新优先（默认，右侧等宽小字「默认」）
  最早优先
只看没看过（开关，不铺选中底）
语言（右侧等宽小字写当前选择：跟随系统 / 简体中文 / English）
```

规则：

```text
默认排序为最新优先
排序作用于当前可见照片全集，再进行日期分组
日期分组顺序和组内照片顺序必须与排序一致
选排序或拨开关后关闭菜单
排序变化仍出现顺序提示；不再旋转排序图标
「只看没看过」开着时 ⋯ 亮 6dp 小点；相似范围忽略这个开关，小点仍按开关本身亮
切换排序后不导航、不刷新权限、不丢掉当前范围和开关
切换排序才做网格重排（每格落定弹簧，步长 14ms）。切换范围或「只看没看过」不位移
```

### 语言切换（⋯ 菜单）

App 界面支持简体中文和英文。默认跟随系统：系统语言是中文（任何地区，含繁体中文 zh-TW / zh-HK）时显示简体中文（资源放在 `values-zh`，繁体脚本另有一份相同的 `values-b+zh+Hant`），其他语言一律显示英文（英文是默认资源）。没有单独的设置页。

入口：照片页顶栏右侧唯一的 36dp 圆形按钮「⋯」。菜单第三段是「语言」，右侧等宽小字写当前选择（跟随系统 / 简体中文 / English）。多选时 ⋯ 换成 ✕。点「语言」关掉菜单再打开弹层。

点「语言」：

```text
所有系统版本（8–16）一律打开 App 内语言弹层，从不跳系统语言设置
（部分国产 ROM 的系统页会落到「添加语言」列表并提示改系统语言）
清单仍声明 localeConfig（en、zh-CN），用户在系统「应用语言」里改过的值弹层能正确读出并改回
```

App 内语言弹层三项，顺序固定：

```text
跟随系统 / Follow system
简体中文
English
```

规则：

```text
「简体中文」「English」用各自的语言写，不随界面语言变化；「跟随系统」随界面语言翻译
当前项 10% 相纸白铺底 + 相纸白 500 + 右侧琥珀勾
点任一项立即生效并关闭弹层；选的就是当前项时只关闭，不重建界面
切换后界面立刻换语言：不重启 App，停留在照片页，排序 / 范围 / 「只看没看过」/ 滚动位置不变（Activity 重建，状态由 ViewModel 和导航保存）
存储：13+ 直接读写系统 LocaleManager（与系统设置、adb 同一份，每次打开弹层读最新值）；8–12 由 AppCompat 保存
任意路径都能来回切：跟随系统 → English → 简体中文 → 跟随系统，强杀重启后保持
点压暗区域或系统返回关闭弹层；弹层打开时底部导航让位隐藏
选择由系统保存：13+ 存在系统「应用语言」里，8–12 由 AppCompat 自动保存（autoStoreLocales），App 不另存
```

日期、数字、文件大小按当前界面语言格式化：中文「9月21日」「9月 · 周三」「周一 · 07:42」；英文「Sep 21」「Sep · Wed」「Mon · 07:42」。时间统一 24 小时制；千分位和小数点用系统本地化格式（中英文都是「1,234」「2.4 MB」）。带数量的文案用复数资源（英文区分「1 photo / 2 photos」）。

### 点击照片

用户点击任意缩略图后（共享元素转场见 ui-design 决定 9：缩略图按下 0.96 → 80–400ms 放大到全屏并由正方形裁切过渡到全屏，settle 弹簧收尾 → 控件淡入）。网格正在上下滚动、或刚停稳约 300ms 内的点按 / 长按会被忽略，避免快速甩动惯性抬手误开清理页；停稳后再点才进入：

```text
进入清理页
从该照片开始清理
```

传递参数：

```text
photoId
sortOrder（当前排序方式）
filterMode（当前范围对应的过滤模式；相似和全部都是 AllPhotos）
scope = AllPhotos
unseenOnly（「只看没看过」是否开着）
```

说明：

```text
清理页会话列表必须继承首页的排序、范围和「只看没看过」
这样清理页中的左右切换顺序才会和用户点击进入时看到的列表一致
scope = AllPhotos 表示上滑手势语义为"收藏"
相似范围不从这里进清理页
```

### 长按多选（批量收藏 / 移入垃圾桶）

进入与退出：

```text
相似范围不能多选，长按无效果
长按任意缩略图（系统长按时长，手指不移出触摸阈值）：进入多选，这一格选中，并给一次长按触感
已在多选中再长按：只是加选这一格，并以它为起点拖选
多选中点缩略图：切换选中，不进入清理页
退出：系统返回（先于退出 App）、顶栏 ✕、取消到一张不剩、执行一次批量动作之后
照片因外部变化从列表里消失：从选中集合里去掉；去到一张不剩同样退出
```

拖选（同 Google 相册）：

```text
长按后不松手拖动：选中 = 长按前已选中的 ∪ 起点格到手指下格子（按列表显示顺序，跨天连续）
往回拖时区间跟着收窄，长按前已选中的保持选中
拖到列表上 / 下边缘 64dp 以内自动滚动，越靠边越快，贴边 14dp / 帧
拖选期间列表本身不跟手滚动；手指落在天标题、年份分隔或空白处时保持上一格
```

天标题：

```text
多选时天标题右侧的「已看 / 总数」换成「全选」；这一天已全部选中时显示「取消全选」
点「全选」补齐这一天；点「取消全选」只取消这一天，其余天的选中保持不变
```

顶栏与底栏：

```text
顶栏没有小标题。大号数字为选中张数，单位 photo / photos 或「张」，副文字「· 已选择」
右侧 ⋯ 换成一个 ✕；左侧和列表位置不动；打开着的菜单关掉；顶栏强制展开
底部导航让位给多选底栏：收藏、移入垃圾桶
```

收藏规则：

```text
选中的照片里只要有一张还没收藏：按钮显示「收藏」，点了只收藏还没收藏的，已收藏的不动
选中的照片全部已收藏：按钮变成「取消收藏」，点了全部取消收藏
撤回胶囊张数 = 实际改变的张数（选 10 张、其中 4 张已收藏 → 「已收藏 6 张」）
```

说明：照片页本身不显示已收藏的照片（收藏后移到收藏页），所以在照片页上实际只会出现「收藏」，混合与「取消收藏」规则写在 UseCase 里，复用到任何会显示已收藏照片的列表。

移入垃圾桶：

```text
选中的全部移入 App 内垃圾桶，包括已收藏的；不弹确认
已收藏的照片在垃圾桶条目里保存收藏快照，收藏页不再显示它；从垃圾桶恢复时收藏跟着回来
永久删除仍只在清空垃圾桶时发生，那里有二次确认
```

撤回：

```text
动作完成后退出多选，显示撤回胶囊，只有一行主文案：
  「已收藏 N 张 · 撤回」「已取消收藏 N 张 · 撤回」「已移走 N 张 · 撤回」
4 秒内点撤回：整批撤回，且只撤这次实际改变的照片
新的批量动作替换上一个撤回胶囊
```

看过：

```text
批量收藏 / 取消收藏 / 移入垃圾桶都把选中的全部照片记为看过（包括收藏时没改变状态的）
撤回不回滚「看过」（与清理页单张撤回一致）
```

数据写入：

```text
批量动作一次写入：收藏 Store、垃圾桶 Store、看过 Store 每个最多一次 edit，不逐张写
```

## 清理页（暗房）

视觉与动效规格见 `docs/ui-design.md` 2.7 与 3.2–3.4、3.10、3.14；以下内容含 2026-10-11 用户最终决定（完整对照表见 `docs/ui-design.md` 第 1 节）。

### 滑动手感硬性要求（逐条验收）

1. 松手判定同时看距离和速度：距离超过阈值，或者朝该方向的松手速度超过甩动阈值（即使距离未到阈值），都算触发。阈值全部定义在 `core/design/Motion.kt` 的 `GestureTokens`：
   - 垂直距离阈值 `VerticalThreshold = 120dp`；横屏按屏幕短边计算（约 120dp）；
   - 垂直甩动速度 `VerticalFlingVelocity = 1000dp/s`，且位移至少 `MinFlingDistance = 24dp`；
   - 水平翻页距离阈值 `HorizontalThreshold = 屏宽 × 0.12（48–96dp）`，水平甩动速度 `HorizontalFlingVelocity = 600dp/s`；
   - 压暗 / 缩放封顶距离 `EffectCapDistance = 170dp`。
2. 当前照片离场时下一张已经就位（后台预先解码好，拖动时不露出；松手后从暗处以 0.94、亮度 ≥ 0.6 起步升起），并且**立刻能接受下一次手势**，不等动画结束。离场动画在上层独立完成，不持有输入锁；连续快速滑动不能丢操作、不能卡住。
3. 左右翻页用 snappy 弹簧（dampingRatio 1.0 / stiffness 1500），1:1 跟手，进入页亮度 0.7 → 1 跟随位移，不缩放、不显影。
4. 收藏和移到垃圾桶的离场动画，主体位移在 250ms 内基本完成；飞向导航、计数弹跳等余韵可以晚一点收尾，但不能挡住下一次操作。
5. 验收：真机上 2 秒内连续处理 10 张，不能丢操作、不能闪、不能卡，录屏附在阶段报告里。

### 手势模型

- 所有手势（上下滑、左右滑、双指缩放、双击、单击）放在**同一个 `pointerInput`** 里用 `awaitEachGesture` 统一判定，不拆父子层。
- 单指一移动超过 touch slop 立刻进入拖动，不等待双击超时；双击只在两次快速按下且都未超过 slop 时成立（1× 时以点按位置放大到 2×，放大时还原，落定弹簧）。
- 单击照片：等系统双击超时后再切换详情。进入清理页只显示顶部进度条；点一次显示左上角返回、中间日期、底部文件名 · 大小（视频再加时长），再点一次收回。左右滑动、上下拖动一开始就收回这些详情，松手后不自动再出现；与手势等价的上一张 / 下一张 / 收藏 / 移入垃圾桶同样收回。进度条不跟着收回。没有右上角「去垃圾桶 / 回到照片」。双击缩放不会先把详情闪出来。系统返回不依赖这个按钮。
- 抬起事件自带的最后一段位移也计入拖动（`ReviewGestureMath.upEventDrag`）；抬起前尚未定方向但总位移已过 slop 时补一次开始拖动，避免快速连滑时一次过阈值的滑动被判成未过阈值或点按。
- 方向判定：越过 slop 后，`|dx| ≥ |dy| × 1.2` 为水平，`|dy| ≥ |dx| × 1.2` 为垂直，否则继续等待。方向一旦确定，本次拖动只走该方向。
- 拖动中的即时值用 `MutableState` 直接赋值；`Animatable` 只用于松手后的动画，并继承松手速度；新手势打断弹簧时以当前速度为初速度。
- 放大状态（scale > 1）下禁用上下处理手势；缩放范围 0.8–3.0，静止范围 1.0–3.0，越界用 bouncy 弹簧回弹。

### 上下拖动表现（决定 3、4）

- 上下位移与手指 1:1。照片 scale 随距离线性 1 → 0.9（170dp 封顶），上下两方向一致。
- 下滑：饱和 1 → 0.35、亮度 1 → 0.55 随距离连续变化，过阈值不跳档；四周加极淡中性暗角，房间底色不变。
- 上滑：底部琥珀显影光，强度随距离变化（未过阈值约 38%）。
- 过阈值松手后，「松手收藏 / 松手移到垃圾桶」圆钮和底部琥珀光（下滑为暗角）保持满强度，随离场 266ms 线性淡出，不在松手当帧消失。
- 提示圆：描边进度 = 距离 / 阈值；未过阈值是 32dp 空心细线圆 + 「继续上滑收藏 / 继续下滑」横向胶囊；过阈值瞬间变 56dp 实心（上滑琥珀 + 6dp 光晕 + 照片琥珀描边；下滑相纸白），减速进入 + 1.14 过冲 pop，同时触感（分级见 ui-design 2.6）；拖回阈值内原路退回，加速离场 100ms，再一次更轻的触感。
- 已打开的返回、日期和文件信息在拖动开始时收回，松手后不自动再出现。进度条在拖动开始 80ms 内淡出，松手或换页后回来。
- 没触发时松手：settle 弹簧（0.75 / 400）带松手速度弹回。

### 离场与下一张

- 收藏：从松手时的实际缩放开始，顺惯性略上冲后加速落入底部「收藏」位置，scale → 0.05，两层余影为照片本身的半透明副本（延迟 50 / 100ms，透明度 0.4 / 0.18），带 1px 琥珀描边（rgba(242,169,59,.4)）与向下 24 偏移、70 模糊的琥珀光晕（.38），随副本一起缩放，对应设计稿动效 04；复用已解码图片，不额外解码（2026-10-17 起，此前为纯色琥珀块）。用户决定（2026-10-17）：离场与撤回时底部导航胶囊都不浮现（不再作为落点短暂出现），清理页全程不显示导航。主体位移 250ms 内基本完成。
- 移到垃圾桶：继续下沉 + 压暗 + 去色 + 缩小落入「垃圾桶」，无余光；垃圾桶计数向上滚一格。主体位移 250ms 内基本完成。
- 用户决定（2026-10-11，覆盖此前「下一张垫在下面」）：上下拖动时**不露出下一张**：上滑露出暗房底色 + 琥珀显影光（未过阈值约 38%，过阈值后琥珀描边）；下滑保持暗房底色 + 极淡中性暗角。下一张在后台预先解码（组合但不可见）。
- 下一张：松手后从底部暗处升起，≤ 280ms（起始亮度 ≥ 0.6，scale 0.94 → 1 settle 弹簧），并立即接受下一次手势、不丢操作。若该图第一次从磁盘解码，才走单张显影；命中缓存不显影。显影期间不拦截手势。
- 系统「移除动画」时：直接换下一张，只显示撤回条与计数变化。

### 左右翻页与跨天（决定 1）

- 整个会话（继承入口排序与筛选）连续翻页，可以跨天。一天的首尾张不加阻尼。
- 只有在整个会话第一张继续右滑、最后一张继续左滑时，位移按阻尼 `offset = L·(1 − 1/(d·0.55/L + 1))`（L = 屏宽 × 0.3）衰减，并露出「最后一张 / 第一张」提示；松手 settle 弹簧回位。
- 跨进新的一天时不阻塞：顶部日期里程表式滚到新日期（逐位滚动，settle 弹簧）；进度条以 short（150ms）交叉淡入切换成新一天的分格；触发一次 `CLOCK_TICK` 轻触感。
- 自绘三页（上一张 / 当前 / 下一张）放在同一个 `Box`，不用 HorizontalPager。
- 左右翻页不显影；往回翻、命中缓存都不显影。
- 左右翻页不移除照片、不改收藏状态、不显示撤回。

### 当天进度条

- 顶部显示「当前照片所在那一天」在本次会话中的进度：一格一张，2dp 高、3dp 间隔；收藏 = 琥珀、移走 = 退影灰·深实线、看过保留 = 相纸白 78%、当前 = 相纸白发光（1.6s 呼吸）、未处理 = 虚线。超过 40 张的一天改为连续细线比例条。不显示数字。
- 处理一张时该格从左向右填色 280ms（标准曲线），光点 150ms 移到下一格。
- 从收藏进入（scope = Favorites）时，上滑「取消收藏」的格子画成**空心琥珀格**（用户决定 13）。

### 小结插页（决定 2）

- 小结不是弹窗，而是翻页序列里两天之间的一张「插页」，不阻塞。
- 触发需同时满足：
  1. 用户离开某天进入下一天（左右滑跨天，或操作后自动前进跨天都算）；
  2. 这一天的照片在本次会话里全部看过或处理过（被跳过、看过未处理的算「保留」）；
  3. 这一天至少有 6 张照片。
- 满足时在两天之间插入小结页；左滑一下或点「下一天」继续进入下一天，点「回到照片」退出清理页。往回滑不触发。同一天在一个会话里最多出现一次。不满足条件就直接进入下一天。
- 用户决定（2026-10-11）：小结页上的上下滑不触发任何操作，只按边缘阻尼跟手一点，松手用 settle 弹簧回弹作为反馈；不新增参数，仍在同一个 pointerInput 里判定，不阻塞左右翻页和下一次手势。
- 取消收藏单独计数（「取消收藏 N」），不并入收藏或保留（决定 13）。月份条发光的是小结对应的那一天（决定 14）。
- 内容（视觉见 `docs/ui-design.md` 3.4）：收藏 / 移走 / 保留 / 可释放空间、比例条、前 8 张缩略条、本月每天的进度（月份条；「整理完的天」跨会话计算，见决定 12）、「下一天」卡带封面与未看数。
- 入场动效按 `docs/ui-design.md` 2.7「小结插页入场」，但任何时刻都可以左滑继续，不等动画结束。入场没播完就翻走、再翻回来时，从停下的位置按原速度播完剩余部分（不重播、也不停在半截）。

### 撤回

- 每次有效操作后显示撤回胶囊：带被处理照片的圆形小样；移入垃圾桶时小样去色压暗、描边与倒计时为中性灰，收藏时为琥珀；底部 2dp 细线倒计时 4 秒。上下拖动时隐藏；4 秒按真实时间从操作那一刻算，隐藏期间照常走，重新出现时细线从剩余比例接着走，不重新计时。
- 点撤回：撤回条加速离场 200ms 收起，照片从去处减速飞回中央（450ms），飞到一半开始重新显影；当前那张退后压暗让位；计数向下滚一格。
- 撤回收藏 / 取消收藏 / 移入垃圾桶的数据处理与以前一致（都只写 DataStore，不触发系统授权，照片插回原位置并切回该照片）。

### 方向提示小点（决定 10）

- 2026-10-23 起清理页不再绘制「上滑收藏 / 下滑移走」。
- 成功上下滑仍把次数写入 DataStore（`review_swipe_action_count`），界面不读这个数。

### 首次教学

- `has_seen_review_tutorial == false` 时显示：照片压暗到 32%，28dp 光点依次演示上滑（琥珀）、下滑、左右（相纸白），每段 2.4s；三行文字依次点亮。教学期间不显示进度条和撤回。点「知道了」或完成任意一次滑动后永久关闭。

### 快速连续滑动

- 不再用全局 `isProcessingAction` 锁拦截手势。每次触发立即产生一个操作并入队到 ViewModel，ViewModel 按顺序串行执行 UseCase；UI 在触发瞬间就切到下一张。
- 同一张照片不会被重复处理（以 photoId 去重）。
- 操作失败：照片插回原位置并提示，后续已入队的操作照常执行。

### 操作失败处理

- 收藏 / 移到垃圾桶失败：照片回到会话中原位置，显示错误提示。
- 撤回失败：保持当前状态，显示撤回失败提示。

### 会话结束

- 会话最后一张被处理后：若最后一天满足小结条件，显示小结插页（「下一天」按钮隐藏，只留「回到照片」）；否则回到入口页。
- 旋转屏幕时保持当前照片。横屏规格见 `docs/ui-design.md` 3.14。
- 照片保持原始比例居中，没铺满的地方是同一张照片的模糊环境光（API 31 以下为暗房底色）。环境光预先做好，跟照片一起移动、缩放，左右滑入时已经在。放大后拖动以照片实际显示大小为界：放大后仍没超出屏幕的那一轴不能拖，超出的拖到照片边缘为止。

## 相似照片页交互

### 入口和返回

照片页范围按钮「相似」。选中后当前列表换成相似分组，底部导航保持显示。没有独立路由，没有返回按钮，没有自己的顶栏。切走再切回来不重新比对。不改排序，不改「只看没看过」（相似忽略这个开关）。不能多选。

### 比对

范围是「全部照片」里的图片：`ObserveAllPhotosUseCase` 已经去掉收藏和垃圾桶，这里再去掉视频（`mediaType != Image`）和没有有效拍摄时间的（`dateTaken` 为空或 ≤ 0）。

只给排序后 10 秒内有邻居的照片算 64 位 dHash。Android 10+ 用 `ContentResolver.loadThumbnail` 拿小图，8–9 用 `inSampleSize` 解小图，缩成 9×8 灰度后按行比较相邻像素。同时最多算 2 张。哈希只留在进程内存，重启要重算。某一张取图失败就跳过它，不让整页失败。

第一次切到「相似」才开始收集比对结果，这次进程里再切回来不重新哈希。比对中在列表里显示「正在比对 120 / 860」这种进度。算完一次性列出分组，不边算边插卡片。

### 分组和保留

按拍摄时间升序。相邻两张间隔 ≤ 10 秒，且汉明距离 ≤ 10，算同一组（链式，只和前一张比）。被跳过的照片不参与相邻比较；它两侧若彼此仍在 10 秒内、距离也够近，可以连成一组。凑不满 2 张的不显示。列表按每组最早一张的时间倒序。

每组默认留下像素数（宽 × 高）最大的一张。像素相同留 `size` 更大的，再相同留拍摄时间更早的，仍相同留 id 更小的。点缩略图把保留改成它。这个选择记在页面状态里，同一组还在时不会被下一次扫描盖掉。

留下的缩略图原色，右上相纸白圆勾。其余去色压暗（退影灰，不用红，也不用琥珀）。

### 移走其余

每组一个中性玻璃胶囊「移走其余 N 张」。点了不弹确认，调用 `BatchMovePhotosToTrashUseCase` 把除保留项以外的照片移入 App 内垃圾桶。这些照片离开「全部照片」后，组就凑不满两张，从列表消失。

撤回胶囊与照片页批量撤回同一位置（导航上方），移入垃圾桶的中性样式。相似和照片多选不会同时出现撤回。点「撤回」走 `UndoBatchActionUseCase`，照片回到相册，组再出现。4 秒到期后胶囊消失，不撤回。「看过」标记与照片页批量移走一样，撤回不回滚。

### 空状态

扫描结束且一组都没有时，列表区域居中显示「没有找到相似照片」。导航仍在。

```text
横向切换复用共享横向预览组件（PhotoPager），与清理页的平面轮播切换一致：拖动中当前页与进入页同时可见，当前页滑出、进入页滑入，配合 scale / alpha / zIndex 过渡；落稳后恢复居中 Fit
预览顺序与网格列表顺序一致
不显示清理页的 Favorite / Trash 指示器
不显示底部 XX / 总数
```

顶部栏结构：

```text
左侧：40dp 玻璃返回钮
中间：垃圾桶 + 等宽「i / N」；下方信息行：文件名 · 大小、拍摄日期 · N天前移入
右侧：不放恢复按钮，避免与底部主操作重复
```

底部主操作：

```text
固定按钮文案：移出垃圾桶
```

按钮行为：

```text
52dp 相纸白胶囊；沿用网格的降饱和；不提供单张永久删除，本屏没有红色
成功后照片恢复原色并飞向左上角淡出，自动显示下一张
从 App 内垃圾桶恢复当前正在预览的照片（删除 DataStore 记录）
不弹 App 自定义确认框
不触发系统授权
成功后从预览队列移除当前照片
```

恢复后的切换规则：

```text
恢复前快照当前照片列表和索引，基于快照计算目标照片（不依赖刷新后的流状态）
如果恢复前队列只有 1 张：退出 Preview，回到 Grid
如果当前索引后还有照片，显示原索引位置的新照片（原下一张）
如果当前索引已经是最后一张但前面还有照片，显示新的最后一张
目标照片决定后再刷新列表，刷新失败不推翻恢复结果
```

### 清空垃圾桶

入口：

```text
仅默认网格模式顶部"清空"按钮可触发
多选模式和预览模式下不显示清空入口
```

确认框：

```text
标题：永久删除 N 张照片？
内容：会释放 X GB。删除后无法撤回，系统还会再请求一次授权。
样式：托盘色、圆角 24、背后压暗 64% 且照片去色；「取消」相纸白文字按钮在左，「删除」实心删除红 40dp 胶囊在右（gentle 弹簧入场）
次操作：取消
主操作：删除
```

点击"取消"：

```text
只关闭确认框，不做其他处理
```

点击"删除"：

```text
对当前垃圾桶中的全部照片发起永久删除
```

永久删除成功后：

```text
格子按阅读顺序依次溶解（每格 380ms、步长 60ms：缩到 0.86 + 模糊 5dp(31+) + 亮度 0.3 + 淡出），「可释放」数字 900ms 滚动归零，空状态缓缓浮现
溶解只排可见格子；总时长 = 最后一个可见格子的起点 + 380ms（每格都溶解完）与 900ms 归零取较长者，之后网格收起，再隔 160ms 空状态浮现
关闭确认框
若当前不在默认网格模式，强制回到默认网格模式
清空选中状态
刷新首页列表
刷新垃圾桶列表
显示成功提示：已清空垃圾桶
空状态正文下显示「累计已释放 X」（本次确认删掉的大小已计入；累计为 0 不显示这一行）
```

计入累计的范围：

```text
刷新后，删除前快照里已经不在垃圾桶的照片，按 size 求和（null 记 0）
合计 > 0 才写入 DataStore total_freed_bytes（只增不减）
全部成功、部分残留、Android 8–10 部分删除都只计真正消失的
进程重建后收到授权结果时没有删除前快照，这一次不计入
```

如果永久删除需要系统授权，用户取消时：

```text
关闭系统授权页
保持垃圾桶列表不变
关闭处理中状态
不显示"操作已取消"
```
