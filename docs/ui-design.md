# UI 设计说明（暗房）

## 0. 规格来源与优先级

原始设计稿只私下保存，不随仓库发布；视觉与动效以本文和 `core/design` 里的 token 为准。

1. **本文第 1 节「用户最终决定」**——2026-10-11 用户逐条确认，优先级最高。
2. 本文第 2–4 节：设计系统、动效规格、逐屏画面与组件规格。
3. 本文没覆盖的业务行为以 `docs/product.md`、`docs/interaction.md`、`docs/data-model.md` 为准。
4. 具体数值以 `core/design`（`DarkroomColors`、`DarkroomText`、`Dimens`、`Motion.kt`、`ApiTier`）为准；文档与代码不一致时先按代码，再回头修文档。

只做深色主题。App 不绘制样机状态栏、外框。

## 1. 用户最终决定

总原则：滑动必须干净利落、有爽快感，可以跨天。

### 2.2 字体

- Noto Sans SC 400/500/600/700：正文、标题。
- Schibsted Grotesk 500/600/700：数字，始终 `tnum` 等宽数字。
- IBM Plex Mono 400/500：EXIF、文件信息、序号等小字，`tnum`。
- 全部是本地静态 ttf（`res/font`），不用可变字体；若以后换可变字体须显式 `FontVariation`。

主要字号：顶栏大号张数 30sp/32 行高、字距 -0.02em；单位 13sp dim；未看副标 11sp mono；底部导航 13sp；对话框标题 17sp/24；空状态标题 18sp、说明 13sp/20、最大宽 232dp；「可释放」数字 32sp/36。

行高按 CSS 语义：每行盒子严格等于 lineHeight，半行距上下对称。Compose 1.10 默认 `LineHeightStyle.Mode.Fixed` 会在首末行补齐字体自然高度（Noto Sans SC 为 1.448em），所以 `DarkroomText` 的每个样式都过 `cssLines()`：行高小于字体自然高度用 `Mode.Tight + Trim.Both`，否则 `Trim.None`。落在父行盒里的小字（如「全部看过了」数字下的 11sp 标签，父行 16×1.45）用 `paddingFromBaseline` 复刻基线位置。

窗口底色和 Android 12+ 启动画面都是暗室底 `#0F0E0D`（`res/values*/themes.xml`），冷启动不露白。

### 2.3 尺寸与圆角

- 顶栏：状态栏下 56dp，内边距左右 16、下 8，底对齐，没有小标题。一行大号张数 30/32 + 单位 13sp dim；大字号封顶 1.3，计数行留在这 56dp 里。英文单位用复数：收藏 favorite / favorites，垃圾桶 item / items（中文都是「张」）。照片页的副文字和右侧按钮见 3.1。
- 玻璃圆钮 40dp（清理页、预览），顶栏工具钮 36dp；玻璃 = glass + 16dp 模糊（31+）+ 14% 内描边。
- 背景模糊用 Haze 1.7.0（`core/design/GlassBackdrop.kt`）：页面根部 `GlassBackdropHost`，被模糊内容加 `glassBackdropSource()`，玻璃组件用 `glassBlur(GlassSpecs.Nav / Button)`。API 31+ 真模糊（导航 20dp、圆钮 16dp），26–30 只用同一玻璃色压暗；开关只看 `ApiTier.hasBlur`。Haze 1.7.1+ / 2.x 要求 compileSdk 37，项目为 36，故锁 1.7.0；该版本不支持背景饱和度，导航 `saturate(1.3)` 暂未实现。
- 底部导航：44dp 高玻璃胶囊居中，距底 24dp，内边距 4dp，圆角 22dp，每项 72×36dp；选中项相纸白字 500 + 16×2dp 下划线（距底 3dp，圆角 1dp）；垃圾桶计数徽标 16dp 高、圆角 8、10% 相纸白底、dim 字 10sp。
- 进度条 2dp 高、3dp 间隔，距屏左右 16dp；>40 张改连续比例条。
- 未看标记：6dp 相纸白光点 + 1.5dp 暗环 + 8dp 柔光。
- 菜单 192dp 宽、圆角 16、内边距 4；菜单项 44dp 高、圆角 12。
- 对话框圆角 24、左右边距 24；背后压暗 64%。
- 主按钮：52dp 相纸白胶囊（授权、预览）；小号 36dp。

### 2.4 Motion token（`core/design/Motion.kt`）

时长：micro 100 / short 150 / medium 280 / long 450 / develop 600 / stagger 40（最多 12 步）/ 开播延迟 `PLAYBACK_START_DELAY` 250。动态照片播完后视频层淡出用 short。中心播放键出现 / 消失也用 short，缩放起点 `MotionScales.REVEAL` 0.92（菜单同一常量，菜单时长仍是 180，原点在右上角）。另有的具名时长（菜单 180、呼吸 2.4s / 1.6s、空状态周期 3.6s、溶解 380/60、多选 160 等）也集中定义在 Motion.kt。进度轮询 200ms 写在播放器里，不是动效 token。

曲线：标准 (0.2,0,0,1)、减速进入 (0.05,0.7,0.1,1)、加速离场 (0.3,0,0.8,0.15)、显影 (0.45,0,0.2,1)。

弹簧（mass=1）：snappy 1.0/1500、settle 0.75/400、bouncy 0.5/400、gentle 0.85/200。

### 2.5 显影

- 单张（缩略图首次解码、撤回回位）：亮度 0.06→1（0–500ms）、反差 0.55→1（80–600ms）、饱和 0→1（200–600ms），显影曲线，scale 1.035→1；API 33+ 叠 AGSL 颗粒 0.55→0。
- 加载（列表骨架之后）：亮度 0→1、反差 0.6→1、饱和 0→1，320ms 减速曲线，同一行 40ms 错开。
- 网格首屏：沿对角线分批显影，单格 520ms，按行+列步长 55ms，最多 12 步，显影曲线，起点亮度 0.08 / 反差 0.6 / 饱和 0；只在本进程第一次出现该网格（照片 / 收藏各一次）时对首屏格子播放（开始滚动前绑定的格子）；切 Tab、从清理页返回、滚动回来都不重播。相似列表第一次出组时同样播一次（见 3.18）。
- 网格滚动进入：开始滚动后新绑定的格子不再显影，解码后直接显示（命中内存缓存亦同）。网格请求关闭 Crossfade，缩略图走系统 `loadThumbnail`（API 29+）。
- 清理页约束（决定 7）：显影不拦截手势；只在第一次从磁盘解码时触发，命中缓存、往回翻、左右翻一律不显影；操作后下一张出场起始亮度 ≥ 0.6、时长 ≤ 280ms，配合 0.94→1 的 settle 弹簧。

### 2.6 系统动画缩放与 API 分级

- 系统「移除动画」（animator duration scale = 0）时所有动画直接显示终态，无限循环（呼吸、空状态、晾片）停止；去向提示退化为计数变化 + 撤回条。清理页和垃圾桶预览此时不自动播放，视频进入就是未开始，中心播放键直接出现。单击照片或「动态」胶囊可手动开始。视频播完回到第 0 帧，动态照片只播一次。
- API 分级集中在 `core/design/ApiTier.kt`：
  - 显影颗粒：33+；模糊 RenderEffect：31+（含玻璃背景模糊 Haze），以下用压暗代替；
  - 触感：34+ `GESTURE_THRESHOLD_ACTIVATE/DEACTIVATE`，30+ `CONFIRM/REJECT`，26–29 `VIRTUAL_KEY`；跨天 `CLOCK_TICK`（全版本）；
  - 预测性返回：34+ 且动画开启（`core/navigation/PredictiveBack.kt`）：拖动时整页按真实布局缩到 0.86、圆角 0→20dp、朝手势方向偏 ≤ 8dp，后面露出上一页快照（亮度 0.3→0.6，快照在离开网格时截取）；提交后共享元素从缩小后的位置收回，中途拖回弹簧回全屏；清理页与垃圾桶全屏预览都支持。以下或动画关闭时直接播放共享元素收回 / 普通返回。
  - 共享元素收回（返回网格）：总长 400ms = 先在起点停 80ms（与展开的按压档对称，吸收返回瞬间重新组合网格页的长首帧）+ 320ms standard 收进格子。格子一侧的共享元素挂在正方形尺寸确定之后（`PhotoTile.sizedModifier`），否则收回首帧会被压成顶部一块方图。

### 2.7 动效原则与分场景规格

原则：

- **跟手，不预演**：拖动期间照片位移与手指 1:1，阈值、压暗、缩放、圆环都是拖动距离的连续函数，拖动中途不触发定时动画；松手才交给弹簧，并继承手指速度。
- **物理弹簧收尾**：位移、缩放的「落定」一律用弹簧（可打断、能接住速度）；只有颜色、透明度这类没有动量的属性用 tween。
- **显影是唯一的「出现」方式**：亮度先到、反差其次、色彩最后。
- **高频操作快而轻**：左右切换只做位移，不显影、不缩放、不发光；越少见的时刻（一天整理完）越可以舒展。
- **遵守系统动画缩放**，**minSdk 26 分级增强**（见 2.6）：低版本少装饰，不少功能。

| 场景 | 触发 | 时长 / 曲线 / 弹簧 | 属性 |
| --- | --- | --- | --- |

| 过阈值 | 上下拖动越过 120dp | 实心 pop：减速进入约 150ms + 1.14 过冲回落；退回：加速离场 100ms | 提示圆描边进度 = 距离 / 120dp；触感见 2.6 |
| 收藏离场 | 上滑触发 | 主体位移 ≤ 250ms（`EXIT_MAIN_MAX`），减速上冲后加速落入；提示圆钮与琥珀光保持满强度后 266ms 线性淡出 | 从松手时的实际缩放 → 0.05，落点为导航「收藏」；两层余影为照片半透明副本（延迟 50 / 100ms，透明度 0.4 / 0.18）+ 1px 琥珀描边 + 琥珀光晕 `0 24 70 rgba(242,169,59,.38)`，同设计稿动效 04（2026-10-17 起）；底部导航不浮现（2026-10-17 起，清理页全程不显示导航） |

## 3. 画面规格

### 3.2 清理 · 静止

- 照片按原始比例居中（Fit），不裁切；没铺满的地方用同一张照片放大 1.2 倍、模糊 36dp、亮度 40% 做环境光（API 31 以下不画，露出暗房底色），环境光裁在本页内，随照片一起移动、缩放。模糊预先做在小图上，左右邻页一起带上，不在翻页落定后才出现。
- 上下暖黑渐变：顶部从 `#0A0908` 62% 起，底部从 `#0A0908` 70% 起，渐变到透明。只在详情显示时垫在字下面；只剩进度条时不画。
- 进入时只显示顶部当天进度条（见 4.2）。返回、日期、底部文件信息先藏着。点一次照片（等过双击超时，避免和双击缩放叠在一起）才显示，再点一次收回。左右滑动或上下拖动一开始就收回，松手后不自动再出现；进度条仍留着。
- 显示时，进度条下面一行：左侧 40dp 玻璃返回。动态照片详情打开时，右侧是 40dp 高玻璃胶囊「◉ 动态」（图标 18dp，文字 13sp，左右内边距 14dp，图标与文字间距 6dp）。没有「去垃圾桶 / 回到照片」。中间日期 15/20 500（里程表）+ 下一行 mono 10.5/16、字距 0.04em、相纸白 66%「星期 · 拍摄时间」。
- 底部：一行文件信息 mono 10.5、相纸白 62%「名称 · 大小」。视频进度行显示时不再追加时长，总时长只留在进度行右端；进度行不显示时仍追加「 · 时长」。不画「上滑收藏 / 下滑移走」。教学期间仍显示返回和日期，不显示底部文件信息、进度行和中心播放键，也不显示「动态」胶囊。
- 视频层叠在静态图上，同一张 `graphicsLayer`（去色、压暗、圆角、缩放、平移）。TextureView，不透明关掉。按视频自己的宽高比（含像素比）在照片区域内 Fit 居中，不拉成容器的形状；尺寸到达之前 alpha 0。首帧回调之前同样 alpha 0，避免黑帧。静态图的请求、缓存键、显影、环境光不变。左右滑出的那一页在翻页弹簧落定前一直留着定格帧，角色变成上一张 / 下一张也不断。
- 视频单击切换播放 / 暂停。暂停、未开始、播完时，屏幕正中一颗 64dp 玻璃圆。停稳后等待自动播放的 250ms 不算未开始，中心键不出现；系统关闭动画时没有这段等待，中心键直接出现。拖动或点按进度，松手后从该位置直接开始播放。底是实色 `#141210` @ 56%（`DarkroomColors.Glass`）加 14% 细线，不取样模糊：视频画在 TextureView 上，模糊采不到画面。里面是实心 Play，布局 `PlaybackCenterIcon` 36dp；路径在 24 视口里宽 16、高 19.2，视觉重心比中心右移约 1，落在画面上大约宽 24dp、高 29dp。它不是点击目标，跟照片缩放无关。滑动和离场时不显示。出现 / 消失 short + 0.92→1。
- 进度行只在视频详情打开、且当前页就是正在显示的那张时，放在文件信息正上方，左右与文件信息对齐。行高 `PlaybackRowHeight` 48dp。两端时间 mono 10.5、相纸白 62%（`DarkroomText.RvFile`）。轨道 `PlaybackTrackHeight` 3dp，未播 `playbackTrack` 相纸白 24%，已播相纸白。拇指 `PlaybackThumb` 12dp，拖动时 `PlaybackThumbDrag` 16dp。行尾 `GlassButton` 40dp 声音钮，图标 `PlaybackSoundIcon` 20dp。拖动和点按都在这一行自己的 pointerInput 里。相纸白和玻璃，不用琥珀、不用红色。图标是 `DarkroomIcons` 的 Play / Motion / SoundOn / SoundOff。没有底部小播放键，没有 Pause。

### 3.3 清理 · 上滑收藏 / 下滑移到垃圾桶

- 照片像被拎起的相纸：跟手位移，scale 1→0.9（170dp 封顶），随距离出现 32dp 圆角；顶边始终留在状态栏下面。拖动一开始就收回返回、日期和文件信息，松手后不自动再出现。进度条在 80ms 内淡出，松手或换页后回来；撤回条在上下拖动期间让开。
- 拖动时底下**不露出下一张**：上滑露出暗房底色 + 底部琥珀显影光（未过阈值约 38% 强度）；下滑保持暗房底色 + 四周极淡中性暗角，照片饱和 1→0.35、亮度 1→0.55 连续变化。
- 提示：未过阈值是 32dp 空心细线圆（上滑琥珀；下滑相纸白 50%）+ 横向胶囊文案「继续上滑收藏 / 继续下滑」（14/20 500，字距 0.04em）；过阈值瞬间变 56dp 实心圆（上滑琥珀 + 外扩 6dp 光晕，图标色 `#2A1A04`，照片描琥珀边；下滑相纸白），主文案「松手收藏 / 松手移到垃圾桶」15/20 600，下滑副文案 mono 11/16「清空前都能找回」，不弹确认。

### 3.4 小结插页

- 背景：当天照片模糊 36dp、亮度 0.32、饱和 1.2（26–30 不模糊，压暗到 0.2 + 暗角）。
- 内容距状态栏 64dp（横屏 40dp），左右 24dp：mono eyebrow 12/16 字距 0.12em「9月21日 · 周一」，标题 28/36 600「这一天整理完了」。
- 比例条 6dp（段间 2dp、圆角 3dp）：琥珀（收藏）/ 退影灰（移走）/ 相纸白 70%（保留）按张数分段；取消收藏为空心琥珀段。
- 三个大数字 36/40 -0.02em，标签 12/16 dim，「移走」数字用暗一档的灰；附加信息 mono 10.5（可释放空间、取消收藏 N）。
- 缩略条：上方 1dp 细线 + 24dp，前 8 张，间距 4dp、圆角 4dp；收藏描 1.5dp 琥珀边，移走去色压到 30% 亮度，不加斜线。
- 月份条：每天一根 16dp 高竖条；整理完的点亮，小结对应那天发光，没整理的半透明，没照片或未到的天只剩 4dp 底座；标题 12/16 dim。
- 「下一天」：相纸白实心卡 64dp 高、圆角 20dp，左侧下一天封面 48dp，标题 15/20 600 暗室色，副标 12/16 退影灰写未看数，右侧箭头；下面文字按钮「回到照片」13sp dim。会话最后一天只留「回到照片」。

### 3.5 垃圾桶（tab）

- 顶栏没有小标题：一行大号张数 + 单位（中文「张」，英文 item / items），右侧「选择」文字按钮。无返回箭头。多选栏与顶栏同高 56dp，底对齐（取消 / 已选择 N 项 / 移出垃圾桶）。背景就是暗室底，不加红光。

### 3.6 垃圾桶 · 多选

### 3.7 垃圾桶 · 单张预览

- 黑底沉浸，照片 Fit，宽 = 屏宽、状态栏下 144dp，保持垃圾桶的降饱和；左右滑切换。
- 顶栏：40dp 玻璃返回钮 + 居中「垃圾桶」15/20 500 + mono 10.5/16「3 / 22」。动态照片时右侧放同一颗「动态」胶囊，其余时候留空。

- 底部距底 40dp、左右 24dp：52dp 相纸白胶囊「移出垃圾桶」（15sp 600 暗室色），不弹确认；成功后照片恢复原色并飞向左上角淡出，自动显示下一张。无单张永久删除、无红色、不显示底部导航。

### 3.8 收藏（tab）与收藏空状态

## 4. 组件细节

### 4.1 撤回胶囊

组件在 `core/design/UndoCapsule.kt`，清理页、照片页多选和相似移走共用。玻璃胶囊 56dp 高（`#1A1816` 78%），左侧 40dp 圆形小样，文案 14sp 500 + 副文案 11sp dim（照片页批量操作没有副文案）（如「已移到垃圾桶 · 可释放 2.4 MB」「已收藏 · 9月21日 · 第 3 张」），右侧相纸白「撤回」按钮（13sp 600 暗室色）；底部 2dp 细线 4 秒倒计时。移到垃圾桶时小样去色压暗、描边和倒计时为中性灰；收藏时为琥珀。照片页不再有垃圾桶提醒胶囊。

### 4.2 当天进度条

2dp 高、3dp 间隔，距屏左右 16dp，一格一张：收藏琥珀；移走退影灰·深实线 `#4A4541`；看过保留相纸白 78%；当前 `#FFF6E8` 80% + 6dp 发光、1.6s 呼吸；未处理为虚线（3dp 段 / 2dp 隙，相纸白 34%）；取消收藏为空心琥珀格。超过 40 张的一天改连续细线比例条。不写数字。

### 4.3 底部导航

### 4.4 永久删除确认
